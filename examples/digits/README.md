# Trained digits model

This example trains one fixed 64→32 ReLU→10 Softmax MLP using the 1,797-row, 8×8 scikit-learn Digits subset. A stratified split with seed 42 creates 1,347 training rows and 450 held-out rows. IDs are sorted within each partition. There are no overlapping IDs or exact duplicate images across partitions. This local split is not the original UCI evaluation protocol and is not verified to separate writers.

Preprocessing divides pixels by their documented maximum of 16; no scaler or calibration is fitted. Only training arrays reach `fit_classifier`. Architecture, optimizer parameters and seeds are fixed before evaluation; there is no search, test-based early stopping or selection among candidate models. The retained state was generated by the first training run for this experiment.

`model.json` retains the original float64 fitted public numerical parameters, class mapping, dataset hashes, split IDs and optimizer provenance. ONNX export converts weights to float32, with dynamic leading dimension `N`. No pickle or joblib state is loaded. Restoring the retained public attributes supports the pinned sklearn `predict_proba` reference; it is not a general sklearn estimator serialization format.

Independent outputs:

- `probabilities`: pinned sklearn 1.6.1 `predict_proba` using the retained float64 model and the same normalized image values, converted to float32 for tensor comparison.
- `logits`: NumPy float32 dense/ReLU/dense computation from the exported float32 weights.
- Ground-truth labels: installed public dataset labels at the fixed test IDs; these determine accuracy independently of the runtime/reference predictions.

The frozen sklearn reference scores **436/450 (96.89%)**. Both ONNX output tensors must match the references at `rtol=1e-4`, `atol=1e-5`; every complete pass must also have exactly the same predicted classes. The model's 14 classification errors are not runtime correctness failures. No accuracy threshold is silently invented.

Install and prepare:

```sh
python -m pip install -r requirements-real-model.txt
python examples/digits/prepare.py
```

Run the production CLI on the whole held-out set:

```sh
inference-doctor examples/generated/digits/model.onnx \
  --inputs examples/generated/digits/inputs.npz \
  --reference examples/generated/digits/reference.npz \
  --labels examples/generated/digits/labels.npz \
  --batch-size 16 --classification-output probabilities \
  --iterations 5 --warmup 5 --repeats 4 \
  --provider CPUExecutionProvider --provider CoreMLExecutionProvider \
  --output results/local/digits-b16
```

The script uses the retained model by default. To independently retrain the fixed recipe without overwriting that retained state:

```sh
python examples/digits/prepare.py --train --output examples/generated/retrained-digits
```

Optimizer floating-point behavior may vary across platforms. Retraining is not required to reproduce inference comparisons: all providers and batch sizes use the exact retained state and exported model. Changes to a retained model require a separate reviewed update to policy and measurements.
